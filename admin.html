Đồng bộ Google Sheets (tùy chọn)
Khi cài đặt URL này, mỗi lần nhấn "Lưu dữ liệu" sẽ tự động gửi lên Google Sheets, giúp đồng bộ giữa các thiết bị và dashboard đọc được.
Cách tạo Google Apps Script
1. Vào script.google.com → New project
2. Xóa code mặc định, paste code bên dưới vào
3. Sửa SHEET_ID thành ID của Google Sheets của bạn
4. Deploy → New deployment → Web App → Execute as: Me → Who has access: Anyone → Deploy
5. Copy URL và dán vào ô trên
